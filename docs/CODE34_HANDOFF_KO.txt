공식 출처 https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-tiny-q5_1.bin. APK에 포함되며 초기 실행 때 검증 후 별도 noBackup 저장소로 복사한다. 코드·모델 MIT 고지도 APK에 포함했다.
ARM64와 x86_64 JNI를 모두 빌드했다. 공식 APK runtime-pin과 내부 .so/model SHA가 일치한다. 실제 실행은 AOSP35 arm64 AVD에서 확인했으며 물리 ARM64 휴대전화와 x86_64 실행은 NOT_RUN이다. 독립 JNI 빌드는 절대 소스 경로 문자열 때문에 작성자 바이너리와 SHA가 다르므로 byte 재현 일치를 주장하지 않는다.
재빌드는 격리된 공식 NDK r28c(28.2.13676358), CMake, 위 모델이 필요하다. IEUM_ANDROID_NDK_ROOT / IEUM_CMAKE_BINARY / IEUM_ANDROID_WHISPER_MODEL을 지정하고 run_gradle.py를 사용한다. 생성된 모델·JNI 자산은 build 디렉터리에 있고 소스 ZIP에 모델을 중복 포함하지 않았다. 공개 다운로드와 핀은 evidence의 영수증을 따른다.

보호 및 남은 범위
원 request/result 파일ID·digest·lease·business context에 결속된 영수증과 sealed journal을 검증한 뒤 기존 accept gate를 사용한다. fixture/imported 자료를 실제 실행이나 high 분석으로 승격하지 않는다. 모델 불일치와 실행 전 취소는 STT0으로 거부한다.
v1 종료 뒤 취소의 TEXT_STORE_CLOSED 실패를 원 로그로 보존했다. v2는 같은 lifetime monitor로 close/cancel DB 접근을 직렬화했고 최종 A3402가 이를 통과했다. 이는 과거 CP08의 최종 admission 이후 강한 AtomicBoolean 취소 미충족을 해결했다는 뜻이 아니며 그 제한은 남는다.
작은 모델의 원 오인식(예: '켠 적설', 'Symphetic')을 그대로 보존한다. 문맥 의미·high/dot 검토 완료·담당자 확정·기한·서류 완료를 자동 판정하지 않는다. 정확도 benchmark는 NOT_RUN이다.
일반 통화의 생산 Android 연결, 임의 개인 원음 수집, 실제 Google 계정/GMS/Drive/API, 최초 승인 credential 생산 공급자, 정확한 06시 보고와 Kakao 발송은 미연결/NOT_RUN이다. 공개 sandbox의 native transport는 메모리 합성이다. 새 OAuth·실제 자격증명·외부 전송·새 권한·보안 완화·iCloud 정리는 수행하지 않았다.
