## 1. 앱의 목적

### 1.1 해결하려는 문제
- 사용자(아내)는 **건설사 직원(부장)**으로 현장 하나를 맡고 있고, 협력업체·사내 직원과 **하루 약 2시간** 통화한다. 시키는 일도, 받는 부탁도 많다.
- 통화가 많아 **저녁이 되면 누구와 무슨 약속을 했는지 기억하지 못한다.** 메모할 틈도 없다.
- 놓치는 것: 보내기로 한 서류(견적서·도면·계약서), 다시 연락하기로 한 약속, 상대가 하기로 한 일, 업체별 진행 상황, 이름과 소속.

### 1.2 목표
1. **아무것도 누르지 않아도** 통화가 끝나면 저절로 정리된다.
2. 홈 맨 위에서 **"오늘 무슨 통화를 했는지"**를 2~3문장 이야기로 보고, 바로 아래에서 **먼저 볼 체크할 일**을 본다.
3. 아침에 **체크할 일 전부**를 알림으로 받는다(앱을 열지 않아도 읽히고, 알림에서 바로 [다 됐어요]).
4. 전화가 오거나 걸 때 **통화 화면 위 이음 카드**로 그 상대와 약속한 일을 3초 안에 떠올린다.
5. 업체·사람별 **맥락이 쌓여서** 다음 통화 정리가 점점 정확해진다.
6. **녹음 파일은 휴대폰 밖으로 나가지 않는다.**
7. 앱이 일을 못 하면 **앱이 먼저 말한다**(녹음이 안 됨, 업데이트가 안 깔림, 권한이 빠짐, 분석이 멈춤).

### 1.3 사용자와 기기
| 항목 | 내용 |
|---|---|
| 실사용자 | 건설사 직원(아내). 스마트폰은 익숙하지만 앱 설정을 만지는 건 싫어함 |
| 관리자 | 남편(앱 요청자). 개발·시험·판단은 Claude가 전담, 사용자는 "시작/중지"만 지시 |
| 기기 | Galaxy S26, 안드로이드 16. 삼성 전화 앱의 자동 통화 녹음(m4a, 보통 `Recordings/Call`) |
| UX 기준 | **50대 남자가 봐도 편하고, 어떤 기능이 있는지 바로 알 수 있게.** "전문가가 오래 공들인 앱처럼 간단하고 직관적이면서 세련되게, 원하는 정보가 한눈에"(10/30) |

### 1.4 하지 않는 것 (범위 밖)
- 녹음 파일을 서버로 보내는 것, 통화 내용을 외부 서비스(구글 드라이브·카톡 등)에 저장하는 것.
- AI가 체크할 일을 **완료 처리**하는 것(완료는 사람만, AI는 "끝났는지 확인"을 제안만).
- 자막에 근거가 없는 체크할 일·사람·업체를 만드는 것. 숫자·날짜·규격을 AI가 "고쳐" 적는 것.
- 개인 통화를 정리하는 것(개인 번호는 목록에 "개인 통화" 한 줄만, 카드·알림 없음).
- API 키 입력 같은 기술 설정(분석은 Claude 구독 방식이라 넣을 것이 없다).

## 2. 전체 동작 (사용자에게 보이지 않는 부분)

```
① 통화 종료 → 앱이 전화 상태로 바로 알아차림
② 녹음 폴더에서 새 녹음 발견(통화 직후 + 주기적 안전망), 통화기록과 짝지음(파일 이름의 상대 먼저)
③ 폰 안에서 Whisper로 자막(녹음 1분당 약 72~85초, S26), 긴 통화도 이어서 끝까지
④ 자막과 맥락(장부의 사람·업체, 최근 통화, 열린 체크할 일, 이름 목록)을 비공개 우편함에 올림 — 녹음 파일은 안 올림
⑤ Claude 예약 작업(매시 34분, 07:34~22:34)이 분석해 결과와 "오늘 통화 이야기"를 씀
⑥ 폰이 루틴 일정의 3·8·15분 뒤에 결과를 받아 검증(인용 대조, 숫자 가드, 없는 이름 버림) 후 적용
⑦ 통화마다 알림 "정리됐어요", 저녁 7시 통화 정리, 아침 6시 체크할 일, 새벽 정리(05:16)가 진행 중인 일과 팔로업을 제안
⑧ 새 버전은 앱이 스스로 확인하고 받아 설치(가능한 폰에서는 누르지 않고)
```

### 분석 결과에 들어가는 것
| 항목 | 화면에서 |
|---|---|
| 요약 | 통화 상세 맨 위, 홈 이야기·메모의 첫 문장 |
| 중요한 내용 | 요약 아래 짧은 줄들 |
| 체크할 일 | 내가 할 일과 상대가 할 일 모두. 업체 이름, 요청 날짜, "제가 하기로/상대가 하기로", 자막 원문 인용 |
| 상대 | 이름, 소속 업체, 직함, 우리 직원 여부(장부에 쌓임) |
| 확실성 | 잘못 들렸을 수 있는 숫자·날짜는 "확인 필요" |

### 안전장치 (사용자가 믿을 수 있게)
- 자막에 실제로 나온 체크할 일만 남긴다(인용이 자막과 맞아야 함). 근거가 약하면 버리지 않고 "확인 필요".
- 자막·이름 목록에 없는 사람/업체 이름은 버린다. 이름·호칭·업체명만 이름 목록 표기로 바로잡고, 숫자·날짜·규격은 들린 대로 둔다.
- 숫자만 다른 일은 합치지 않는다(13층과 30층은 다른 일).
- 사용자가 고친 것, 완료한 것은 AI가 바꾸지 않는다. 사람 합치기는 되돌릴 수 있다.

## 3. 기능 목록 (화면별)

아래 탭 막대 다섯 개: **홈 / 통화 / 체크 / 업체 / 설정.** 사람 화면은 탭이 없고 연 화면으로 돌아간다. 앱을 열면 약 1.2초 시작 화면("당신의 통화 에이전트" 위로 "이음", 누르면 넘어감).

### 3.1 홈 (요약만, v3.2부터)
위에서부터:

| 순서 | 요소 | 내용 |
|---|---|---|
| 0 | 머리 | 시간대 인사("좋은 아침이에요/좋은 오후예요/좋은 저녁이에요")와 날짜 |
| 1 | "설정에서 확인할 일이 있어요 ›" | 할 일이 있을 때만 앰버 한 줄: 필수 처음 설정이 남음, 모델 받기 실패, 녹음 공백 확정, 업데이트가 사람을 기다림. 누르면 설정의 그 줄로 |
| 2 | 오늘 통화 이야기 | 제목 "오늘 통화 n건" + "전체 보기 ›", 본문은 매시간 루틴이 쓴 2~3문장(최대 4줄, 자르지 않음). 이야기가 없으면 오늘 정리된 통화의 "상대: 첫 문장"을 최신 3개까지. 정리된 통화가 없으면 "오늘은 아직 정리된 통화가 없어요". 누르면 오늘 통화 |
| 3 | 먼저 볼 체크할 일 | 오늘 요청된 것과 "끝났는지 확인"인 것, 최대 5개, 각자 [다 됐어요]. 나머지는 "외 n개 보기 ›". 없으면 "오늘 요청된 체크할 일이 없어요" 또는 "체크할 일이 없어요" |
| 4 | 오늘 통화 메모 | 오늘 통화 최신 4개: 시각, 상대, 요약 첫 문장. 정리 전이면 "오늘 통화 n건을 정리하고 있어요" |
| 5 | 오늘 한눈에 | 큰 숫자 셋 "오늘 통화 n건 / 오늘 생긴 체크 n개 / 남은 체크할 일 n개"(마지막만 강조색), "다음 알림 오늘 저녁 7시 (통화 정리)", 정리 중이면 "정리 중 n건" |
| 6 | 업체별 체크할 일 | 열린 체크할 일이 많은 업체 5곳까지 막대 |
| 7 | 이번 주 통화 | 최근 7일 막대, 마지막 칸 "오늘" |

처음 설정, 지난 통화 정리 진행, 모델 받기, 업데이트 받기·설치, 녹음 공백 안내는 홈에 없고 설정 맨 위 "지금 할 일과 진행 상황"에 있다.

### 3.2 오늘 통화 (통화 탭)
| 요소 | 내용 |
|---|---|
| 머리 | "오늘의 통화"(다른 날은 "11월 4일 (화)의 통화"), 아래 "통화 7건, 부재중 2건, 문자 1건" |
| 찾기 | "업체, 사람, 통화 내용 찾기"(10/1부터 전부). 사람이 맞으면 "사람" 절이 통화 위에 최대 5명 |
| 날짜 | ‹ 날짜 ›, 오늘이 아니면 "오늘로 돌아가기 ›" |
| 목록 | 정리된 통화·문자·메일과 **폰 통화기록의 모든 통화**를 시간순 한 목록으로. 통화기록 줄: "부재중 전화"[다시 걸기], "건 전화, 연결 안 됨"[다시 걸기], "차단한 번호의 전화", "받은 전화 3분, 녹음을 글자로 바꾸는 중이에요 / 녹음을 찾는 중이에요(통화 뒤 10분) / 녹음 없음", "개인 통화" |
| 정리 상태 | "정리하고 있어요", 6시간 넘으면 "정리가 늦어지고 있어요", 말소리가 없던 녹음은 "녹음에서 말소리를 찾지 못했어요"(버튼 없음) |
| 상세 | 제목은 상대 이름(누르면 사람 화면) + 날짜·시각·길이 + 전화 걸기 버튼, "○○ 님 보기 ›", "업체 보기 ›" → 정리 못 한 통화는 앰버 상자와 [다시 정리하기](적용 실패는 "정리 결과를 적용하지 못했어요") → "요약"(요약 + 중요한 내용) → "이 통화에서 생긴 체크할 일"(열린 것은 [다 됐어요], "제가 하기로/상대가 하기로", 인용 ‘…’, "확인 필요" 배지) → [통화 내용 전체 보기]/[접기](자막, 14일 보관) |

### 3.3 체크할 일 (체크 탭)
| 요소 | 내용 |
|---|---|
| 머리 | "체크할 일", "n개 남았어요" |
| 묶음 | 끝났는지 확인해 주세요 / 오늘 요청한 일 / 어제 요청한 일 / 그전에 요청한 일(빈 묶음은 숨김). 14일 넘은 것은 "오래된 일 n개 보기 ›"로 접힘 |
| 행 하나 (모든 화면 공통) | ① 업체 배지, "확인 필요" 배지, 상태 알약(끝났는지 확인/진행 중/기다리는 중) ② 제목(META와 겹치는 "○○ 님께"는 뺌) ③ META "김민수 님, 오늘 요청"(이름을 누르면 사람 화면) ④ "AI 메모: …" ⑤ [다 됐어요] |
| 누르기 | 통화에서 생긴 일만 그 통화를 연다. 직접 적은 일·새벽 팔로업은 눌림 표시 없음 |
| [다 됐어요] | 누르는 즉시 흐려지고 "끝낸 일로 옮겼어요 [되돌리기]" 띠 |
| 아래 | "끝낸 일 보기 (7일) ›", [+ 직접 적기](제목과 업체를 골라 저장) |

### 3.4 업체와 사람 (업체 탭)
| 요소 | 내용 |
|---|---|
| 목록 | "업체 n곳, 최근에 통화한 순서예요", 찾기 "업체, 사람 찾기". 행: 공종 배지, 업체명, "체크할 일 n개, 어제 마지막 통화" |
| 업체 없는 사람 | "업체 없는 사람 (우리 직원 등)" 절, 행을 누르면 사람 화면 |
| 업체 상세 | 업체명 + "공종 철근" + 전화 걸기(가장 최근 사람), [업체 이름 고치기] → 업체 메모 → 진행 중인 일 (n)(있을 때만) → 사람 (n) → 체크할 일 (n) → 최근 통화(이름을 누르면 사람 화면) |

### 3.5 사람 (v2.8부터, 이름을 누르면 어디서나)
머리: 이름, "탄탄이엔씨 대표"(우리 직원이면 "우리 직원 공무"), 둥근 [전화 걸기] [문자 보내기](번호는 화면에 쓰지 않음). 같은 번호를 여럿이 쓰면 "이 번호를 쓰는 사람: 박영희 대리 외 1명"과 사람 칩.
순서: 마지막 통화("11월 4일 (화) 오후 2:10, 3분 12초, 받은 전화") → 체크할 일 (n)(전부, [다 됐어요]) → 진행 중인 일 → 최근 통화와 문자(10건) → 글자 링크 [이름 고치기](옛 이름은 별칭으로 남아 같은 오인식도 이 사람에 이어짐), [이 번호는 개인으로 두기](확인 시트, 설정에서 되돌림).

### 3.6 설정
머리 "설정, 처음 설정한 것도 여기서 언제든 바꿀 수 있어요". 주황 신호등이 하나라도 있으면 "지금 상태"가 맨 위로 온다.

| 묶음 | 내용 |
|---|---|
| 지금 할 일과 진행 상황 | 녹음 공백 한 줄("녹음이 들어오지 않고 있어요. 아래 지금 상태에서 볼게요 ›"), 처음 설정(3.7), 지난 통화 정리("녹음 120개 중 59개 남음", 쉬는 이유 "잠시 쉬고 있어요/충전기에 꽂으면 이어서 정리해요"), 음성 인식 모델("받는 중 42% (241MB / 574MB)" 막대, [다시 받기]). 할 일이 없으면 "지금 할 일이 없어요. 모두 잘 되고 있어요 ✓" |
| 연결 | 녹음 폴더, 문자, 통화기록, 통화 끝 알아차리기(전화 상태), 메일(IMAP, 네이버 등 안내). 각각 "허용됨 ✓ …" 또는 이유 + 버튼, 막혔으면 [앱 정보 열기]와 제한된 설정 안내 |
| 통화 카드 | 다른 앱 위에 표시 허용, 스위치 "전화 올 때", "전화 걸 때", 선택 제안 "거는 전화에 번호를 더 빨리 알기"([허용하기]/[괜찮아요]), "아직 정리된 통화가 없는 번호도"(기본 끔), "잠금 화면에서도 이름과 한 줄 보기"(기본 켬), [카드 위치 처음으로] |
| 정리 | 정리 동의 스위치(녹음은 폰 밖으로 안 나간다는 설명), 알림 시각 "저녁 통화 정리"(15~23시, 기본 19시)와 "아침 체크할 일"(4~11시, 기본 6시), "통화마다 알림", "새 버전은 자동으로 설치"(+ 필요하면 [설치 허용]), 내 정보(이름, 회사와 현장, 직책), 개인으로 둔 번호(되돌리기) |
| 상태와 도움 | 지금 상태 신호등 여섯 줄(녹음 가져오기, 글자로 바꾸기, 통화 정리, 알림, 업데이트, 통화 카드: 초록 "정상" 또는 앰버 이유와 할 일 한 문장, 빨강 없음, 줄을 누르면 고칠 곳으로), 앱 버전과 업데이트([지금 확인 ›], 받는 중 %, [지금 설치]/[지금 업데이트], 실패 이유), 저장 공간 %, 음성 인식 모델, 현장 상황 메모 보기, 처리한 통화와 [기다리는 통화 다시 정리하기], [상대 카드 다시 만들기], [합친 사람 되돌리기], [문제 알리기], 맨 끝 숨김 링크 "골든 측정 ›"(자막 정확도 재기) |

### 3.7 처음 설정 (설정 맨 위, 막히지 않음)
"처음 설정 남은 n단계" → "다음 할 일: ○○" 큰 제목 → 이유 문장 바로 아래 버튼 하나. 선택 단계에는 "선택 단계예요. 하지 않아도 이음은 그대로 돌아가요."와 [나중에 할게요](설정에 남음). 첫 실행에만 펼쳐 보인다.

| 구분 | 단계 (버튼) |
|---|---|
| 필수 | 녹음 폴더 연결 [녹음 폴더 고르기] → 정리 동의 [동의하고 켜기](동의 즉시 모델 574MB를 어떤 연결에서든 받기 시작) → 통화기록 읽기 허용 → 통화가 끝난 걸 바로 알아차리기 [전화 상태 허용] → 알림 허용 [알림 허용하기](두 번 거절 뒤 [알림 설정 열기]) → 배터리 제한 풀기 [제한 풀기] |
| 선택 | 문자 읽기 허용 → 통화 화면 위에 이음 카드 보기 [카드 보기 허용](돌아왔는데 안 켜졌으면 "목록에서 '이음'을 찾아 스위치를 켜 주세요"를 굵게 + [다시 열기]) → 새 버전을 저절로 설치하기 [설치 허용] |

거는 전화 역할은 처음 설정에 없다(v3.4부터 카드가 역할 없이 뜸). 거부해도 다음 단계로 간다.

### 3.8 알림
| 알림 | 시각 | 제목 / 내용 | 누르면 |
|---|---|---|---|
| 통화마다 | 통화 직후 | "김민수 대표와 통화를 정리하고 있어요 / 끝나면 여기에 요약이 와요" + [메모 남기기](한 줄 → 체크할 일) → "김민수 대표와 통화가 정리됐어요" + 요약 첫 문장 + "체크할 일: … 외 n개". 늦으면 "정리가 늦어지고 있어요"(기록이 있을 때만 ", 저녁 보고에 넣어 드릴게요"), 녹음이 없으면 "이 통화는 녹음이 없어 정리할 수 없어요". 연결 안 된 발신은 알림 없음. 녹음 꺼짐 판정 중에는 통화별 알림 대신 홈 한 줄 | 그 통화 |
| 저녁 정리 | 19:00(설정) | "오늘 통화 n건, 새 체크할 일 m개", 펼치면 통화마다 "오후 2:10 김민수, 첫 문장"(7줄까지 + "외 n개"), 정리 중이면 ", 아직 정리 중인 통화가 n건 있어요". 녹음된 통화가 0이면 "오늘 통화 n건, 녹음된 통화 0건" | 그날 통화 |
| 아침 보고 | 06:00(설정) | "체크할 일 n개", 첫 줄 "지금 할 일: [업체] 제목, 오늘 요청" + [다 됐어요](누르면 다음 항목으로, 마지막엔 "체크할 일을 다 끝냈어요"), "끝났는지 확인", "확인 필요", "진행 중, ○○: 현황"(3줄까지), "늦게 정리된 통화 n건" | 체크할 일 |
| 자가 진단 | 저녁 보고 작업 뒤 | 하나면 그 제목, 여럿이면 "이음에서 살펴볼 일이 n가지 있어요": 통화 녹음이 꺼져 있는 것 같아요 / 통화가 일부만 녹음되고 있어요 / 녹음 폴더 연결이 풀렸어요 / 통화 글자 바꾸기가 밀려 있어요 / 음성 인식 모델을 다시 받아야 해요 / 정리가 늦어지고 있어요 / 이음 저장 공간이 거의 찼어요 / 분석이 n시간 안 돌았어요 / 새 버전이 하루 넘게 설치되지 않았어요 | 설정 |
| 새 버전 | 받았을 때(누르지 않고 설치되지 않을 때) | "이음 새 버전이 준비됐어요" + version.json의 notes(= `docs/UPDATE_NOTE.txt` 첫 줄), 설치 확인이 필요하면 "눌러서 설치를 마쳐 주세요" | 설치 |

모든 보고 알림은 BigText로 줄을 자르지 않는다. 잠금 화면에는 "잠금을 풀면 내용이 보여요"(통화마다 알림은 "통화 정리됨 / 확인할 통화 / 통화 정리 중").

### 3.9 통화 카드 (v3.0, v3.4에서 모든 전화로)
| 순간 | 카드 |
|---|---|
| 벨 울림 | 펼친 카드(화면 높이 34% 안, 아래 끝은 72% 위, 기본 38% 지점, 끌어 옮기면 기억) |
| 받음 | 3초 뒤 위쪽(8~20%) 띠로 접힘 "김민수 대표, 견적서 보내기, 금요일까지". 누르면 펼침. 보여 줄 일이 없으면 띠 대신 사라짐 |
| 걸 때 | 위쪽 25% 안에 펼친 채 3초 → 띠 |
| 끊음 | 사라지고 통화마다 알림으로 이어짐 |
| 통화 대기 | 둘째 벨이 오면 카드를 숨기고 다음 통화 끝까지 아무것도 안 띄움 |
| 개인·제외 번호 | 아무것도 안 뜸 |

카드 내용(5줄 이하, 위부터): [접기][닫기] → **첫 줄**(20sp 굵게, 2줄까지, 띄어쓰기에서 끊음): ① 기한이 지났거나 7일 안인 열린 체크할 일 ② "확인 필요"인 일(배지 앞에) ③ 14일 안 지난 통화 요약 첫 문장 ④ 진행 중인 일 ⑤ "3일 전 통화, 30일간 5번" → "김민수 대표, 탄탄이엔씨, 3일 전" → "체크할 일 … 외 n개" → "진행 중인 일 …". 전화번호와 자막은 쓰지 않고 금액·날짜·수량은 보인다. 정리된 통화가 없는 번호는 "아직 정리된 통화가 없는 번호예요" + 통화기록 한 줄(스위치를 켰을 때만).

### 3.10 잠금 화면
- 잠긴 폰에 벨이 오면 카드 창과 내용 있는 알림을 함께 띄우고, 잠금을 풀면 알림을 지운다.
- "잠금 화면에서도 이름과 한 줄 보기"가 켜져 있으면(기본) 이름, 업체, "체크할 일: …" 한 줄(번호·금액·자막 없음). 꺼져 있으면 "이음 통화 카드 / 잠금을 풀면 카드가 보여요".
- 보고 알림과 통화마다 알림은 잠금 화면에 내용 없이(3.8 끝).

## 4. UX 설계 원칙

### 4.1 핵심 원칙
1. **버튼 없는 자동화** — 설정을 마친 뒤 할 일은 "읽기"와 [다 됐어요]뿐. 하루 누름은 아침 0~1, 전화 올 때 0, 저녁 0~1.
2. **홈은 요약, 이동은 아래 탭** — 홈은 이야기와 먼저 볼 체크할 일 같은 요약만. 숨은 메뉴·햄버거 없음. 뒤로는 상세 닫기 → 홈 → 종료, 지금 탭을 다시 누르면 목록 맨 위.
3. **설정에서 한 번에 한 단계** — 지금 할 단계 하나만 크게, 막혀도 다음으로. 홈에는 할 일이 있을 때만 한 줄.
4. **누르면 바로 반응** — 누르는 순간 바뀌거나 "○○하는 중이에요", 두 번 눌러도 한 번만.
5. **근거를 보여 준다** — 체크할 일에 통화 원문 인용, 불확실하면 "확인 필요".
6. **AI는 제안, 사람이 결정** — 완료·이름 고치기·합치기 되돌리기는 사람만.
7. **알림만 읽어도 된다** — 아침 보고는 앱을 열지 않아도 전부 보이고 바로 끝낼 수 있다.
8. **스스로 말한다, 지키지 못할 약속은 하지 않는다** — 안 되는 것은 이유와 할 일을 한 문장으로. 녹음 없는 통화에 "정리하고 있어요"라고 하지 않는다.
9. **개인정보** — 녹음은 폰 안에만, 자막은 14일 뒤 비움(요약은 남음), 화면에 전화번호를 쓰지 않음, 통화 카드 창은 캡처 차단(앱 화면 캡처는 10/30 결정으로 허용).

### 4.2 화면 흐름
```
아래 탭: 홈 │ 통화 │ 체크 │ 업체 │ 설정
홈 ─ "설정에서 확인할 일이 있어요" → 설정의 그 줄
   ─ 오늘 통화 이야기 / 메모 → 통화(상세)
   ─ 먼저 볼 체크할 일 → 그 통화, 이름 → 사람
통화 ─ 통화 상세 ─ 사람 / 업체 / 통화 내용 전체
체크 ─ 행 → 그 통화, META 이름 → 사람
업체 ─ 업체 상세 ─ 사람 ─ 이름 고치기(시트)
설정 ─ 지금 상태(주황이면 맨 위) ─ 지금 할 일과 진행 상황 ─ 연결 ─ 통화 카드 ─ 정리 ─ 상태와 도움
알림: 통화마다 → 그 통화 / 저녁 → 그날 통화 / 아침 → 체크 / 자가 진단 → 설정
통화 화면 위: 이음 카드(벨·걸 때) → 띠 → 끊으면 통화마다 알림
```

### 4.3 시각 디자인 토큰 (`CallUi.kt`)

| 글꼴 | Pretendard 한 가족(굵기로 위계) |

| 밝은 색 | 바탕 `#F2F4F6`, 시트 `#FFFFFF`, 글자 `#191F28`, 보조 `#6B7684`, 강조 파랑 `#3268F0`(연한 `#EDF2FE`), 앰버 글자 `#B26B00`·바탕 `#FFF4E0`·막대 `#F5A524`, 정상 `#0B8A5F` |

### 4.4 글 규칙 (CI `tools/check_ui_rules.py`와 화면 시험이 검사)
- **읽는 글 18sp 이상.** 16sp는 META 줄(누가, 언제)과 배지만(`CallUi.meta`), 새 `caption(` 사용은 경고.
- **가운데 점(·) 금지** — 쉼표나 띄어쓰기, 자연스러운 문장으로("김민수 대표, 탄탄이엔씨, 3일 전").
- **말줄임표(…, ...) 금지, 자르지 않는다** — 목록은 첫 문장만(`firstSentence`), 카드는 띄어쓰기 경계에서. 나머지는 눌러서.
- **"할 일"이 아니라 "체크할 일"** — 상대가 할 일도 체크할 일. 기한 대신 **요청 날짜**("오늘 요청"), "기한"이라는 낱말과 급박한 표시를 쓰지 않는다.
- **숫자는 녹음 기준** — "녹음 n개 중 m개 남음". 통화기록 전체 수는 검증용으로만(하트비트·워치독·검증 작업). 통화 목록에 모든 통화가 한 줄씩 보이는 것은 그대로.
- **지키지 못할 약속 금지** — 녹음이 없는 통화에 "정리하고 있어요", "저녁 보고에 넣어 드릴게요"를 쓰지 않는다. 늦으면 늦다고 말한다.
- 영어 상태값(FAILED 등)·전문용어 노출 금지, "~해요" 체. 루틴이 쓴 이야기도 폰이 가운데 점·말줄임표를 걷어 낸다.
