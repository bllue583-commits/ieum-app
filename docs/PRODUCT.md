## 1. 앱의 목적

### 1.1 해결하려는 문제
- 사용자(아내)는 **건설사 직원(부장)**으로 현장 하나를 맡고 있고, 협력업체·사내 직원과 **하루 약 2시간** 통화한다. 시키는 일도, 받는 부탁도 많다.
- 통화가 많아 **저녁이 되면 누구와 무슨 약속을 했는지 기억하지 못한다.** 메모할 틈도 없다.
- 놓치는 것: 보내기로 한 서류(견적서·도면·계약서), 다시 연락하기로 한 약속, 상대가 하기로 한 일, 업체별 진행 상황, 이름과 소속.

### 1.2 목표
1. **아무것도 누르지 않아도** 통화가 끝나면 저절로 정리된다.
2. 홈 맨 위에서 **"오늘 무슨 통화를 했는지"**를 2~3문장 이야기로 보고, 바로 아래에서 **먼저 볼 체크할 일**을 본다.
3. 아침 5:30에 **카카오톡 "나와의 채팅"으로 아침 보고**(어제 통화 정리, 오늘 챙길 일)를 받고, 6시에는 **체크할 일 전부**를 앱 알림으로 받는다(앱을 열지 않아도 읽히고, 알림에서 바로 [다 됐어요]).
4. 전화가 오거나 걸 때 **통화 화면 위 이음 카드**로 그 상대와 약속한 일을 3초 안에 떠올린다.
5. 업체·사람별 **맥락이 쌓여서** 다음 통화 정리가 점점 정확해진다.
6. **녹음 파일은 휴대폰 밖으로 나가지 않는다.**
7. 앱이 일을 못 하면 **앱이 먼저 말한다**(녹음이 안 됨, 업데이트가 안 깔림, 권한이 빠짐, 분석이 멈춤).
8. **배터리를 녹이지 않는다**(v3.6, 11/7 배포, [DESIGN_V6.md](history/DESIGN_V6.md)): 긴 통화와 밀린 녹음은 충전기에 꽂았을 때 글자로 바꾸고, 배터리로는 오늘의 짧은 통화만 정해진 만큼(하루 20분) 바꾼다. 11/7 실사용에서 이음이 배터리의 약 60%를 쓴 것이 계기.

### 1.3 사용자와 기기

|---|---|

### 1.4 하지 않는 것 (범위 밖)
- 녹음 파일을 서버로 보내는 것, 통화 원문(자막·문자 원문)을 외부 서비스(구글 드라이브·카톡 등)에 저장하는 것. 예외는 아침 보고(v3.5): 요약과 체크할 일만 아내 본인의 카카오톡 "나와의 채팅"으로 보낸다(전화번호·자막·문자 원문은 넣지 않음, 3.11).
- AI가 체크할 일을 **완료 처리**하는 것(완료는 사람만, AI는 "끝났는지 확인"을 제안만).
- 자막에 근거가 없는 체크할 일·사람·업체를 만드는 것. 숫자·날짜·규격을 AI가 "고쳐" 적는 것.
- 개인 통화를 정리하는 것(개인 번호는 목록에 "개인 통화" 한 줄만, 카드·알림 없음).
- API 키 입력 같은 기술 설정(분석은 Claude 구독 방식이라 넣을 것이 없다).

## 2. 전체 동작 (사용자에게 보이지 않는 부분)

```
① 통화 종료 → 앱이 전화 상태로 바로 알아차림
② 녹음 폴더에서 새 녹음 발견(통화 직후 + 주기적 안전망), 통화기록과 짝지음(파일 이름의 상대 먼저)
③ 폰 안에서 Whisper로 자막(실측 녹음 1분당 약 3.5분, S26 백그라운드 — 그래서 v3.6부터 주로 충전 중에), 긴 통화도 이어서 끝까지
④ 자막과 맥락(장부의 사람·업체, 최근 통화, 열린 체크할 일, 이름 목록)을 비공개 우편함에 올림 — 녹음 파일은 안 올림
⑤ Claude 예약 작업(매시 34분, 07:34~22:34)이 분석해 결과와 "오늘 통화 이야기"를 씀
⑥ 폰이 루틴 일정의 3·8·15분 뒤에 결과를 받아 검증(인용 대조, 숫자 가드, 없는 이름 버림) 후 적용
⑦ 저녁 7시 통화 정리 알림 한 통(v3.9부터 통화마다 알림은 녹음 없는 통화만), 새벽 정리(04:46)가 진행 중인 일과 팔로업을 제안하고 아침 보고서를 씀
⑧ 아침 5:30 폰이 그 보고서를 카카오톡 "나와의 채팅"으로 보냄, 6시 체크할 일 앱 알림(카톡이 간 날은 조용히)
⑨ 새 버전은 앱이 스스로 확인하고 받아 설치(가능한 폰에서는 누르지 않고)
```

### 분석 결과에 들어가는 것
| 항목 | 화면에서 |
|---|---|
| 요약 | 통화 상세 맨 위, 홈 이야기·메모의 첫 문장 |
| 중요한 내용 | 요약 아래 짧은 줄들 |
| 체크할 일 | 내가 할 일과 상대가 할 일 모두. 업체 이름, 요청 날짜, "제가 하기로/상대가 하기로", 자막 원문 인용 |
| 상대 | 이름, 소속 업체, 직함, 우리 직원 여부(장부에 쌓임) |
| 확실성 | 잘못 들렸을 수 있는 숫자·날짜는 "확인 필요" |

### 안전장치 (사용자가 믿을 수 있게)
- 자막에 실제로 나온 체크할 일만 남긴다(인용이 자막과 맞아야 함). 근거가 약하면 버리지 않고 "확인 필요".
- 자막·이름 목록에 없는 사람/업체 이름은 버린다. 이름·호칭·업체명만 이름 목록 표기로 바로잡고, 숫자·날짜·규격은 들린 대로 둔다.
- 숫자만 다른 일은 합치지 않는다(13층과 30층은 다른 일).
- 사용자가 고친 것, 완료한 것은 AI가 바꾸지 않는다. 사람 합치기는 되돌릴 수 있다.

## 3. 기능 목록 (화면별)

아래 탭 막대 다섯 개: **홈 / 통화 / 체크 / 업체 / 설정.** 사람 화면은 탭이 없고 연 화면으로 돌아간다. 앱을 열면 약 1.2초 시작 화면("당신의 통화 에이전트" 위로 "이음", 누르면 넘어감).

### 3.1 홈 (요약만, v3.2부터)
위에서부터:

| 순서 | 요소 | 내용 |
|---|---|---|
| 0 | 머리 | 시간대 인사("좋은 아침이에요/좋은 오후예요/좋은 저녁이에요")와 날짜 |
| 1 | "설정에서 확인할 일이 있어요 ›" | 할 일이 있을 때만 앰버 한 줄: 필수 처음 설정이 남음, 모델 받기 실패, 녹음 공백 확정, 업데이트가 사람을 기다림. 누르면 설정의 그 줄로 |
| 2 | 오늘 통화 이야기 | 제목 "녹음 n개 중 정리 m개" + "전체 보기 ›"(v3.9: 오늘 녹음 수는 홈에서 여기 한 번만. 이야기가 아직 없어도 녹음이 있으면 이 제목을 보인다), 본문은 매시간 루틴이 쓴 2~3문장(120자 안에서 문장 단위로, 문장 중간에서 자르지 않음). 이야기가 없으면 오늘 정리된 통화의 "상대: 첫 문장"을 최신 3개까지. 정리된 통화가 없으면 "오늘은 아직 정리된 통화가 없어요". 누르면 오늘 통화 |
| 3 | 먼저 볼 체크할 일 | 오늘 요청된 것과 "끝났는지 확인"인 것, 최대 5개, 각자 [다 됐어요]. 나머지는 "외 n개 보기 ›". 없으면 "오늘 요청된 체크할 일이 없어요" 또는 "체크할 일이 없어요" |
| 4 | 오늘 통화 메모 | 오늘 통화 최신 4개: 시각, 상대, 요약 첫 문장. 정리 전이면 "오늘 통화를 정리하고 있어요. 끝나면 여기에 메모가 보여요" |
| 5 | 오늘 한눈에 | 큰 숫자 둘 "오늘 생긴 체크 n개 / 남은 체크할 일 n개"(마지막만 강조색), "다음 알림 오늘 저녁 7시 (통화 정리)". v3.9에서 "오늘 녹음" 숫자와 알약 "녹음 n개 중 정리 m개"를 지웠다(같은 숫자를 세 번 보였음) |
| 6 | 업체별 체크할 일 | 열린 체크할 일이 많은 업체 5곳까지 막대 |
| 7 | 이번 주 통화 | 최근 7일 막대, 마지막 칸 "오늘" |

처음 설정, 지난 통화 정리 진행, 모델 받기, 업데이트 받기·설치, 녹음 공백 안내는 홈에 없고 설정 맨 위 "지금 할 일과 진행 상황"에 있다.

### 3.2 오늘 통화 (통화 탭)
| 요소 | 내용 |
|---|---|
| 머리 | "오늘의 통화"(다른 날은 "11월 4일 (화)의 통화"), 아래 "통화 7건, 부재중 2건, 문자 1건" |
| 찾기 | "업체, 사람, 통화 내용 찾기"(10/1부터 전부). 사람이 맞으면 "사람" 절이 통화 위에 최대 5명 |
| 날짜 | ‹ 날짜 ›, 오늘이 아니면 "오늘로 돌아가기 ›" |
| 목록 | 정리된 통화·문자(메일은 v3.7에서 지움, 그 전에 정리된 메일은 남음)와 **폰 통화기록의 모든 통화**를 시간순 한 목록으로. 통화기록 줄: "부재중 전화"[다시 걸기], "건 전화, 연결 안 됨"[다시 걸기], "차단한 번호의 전화", "받은 전화 3분, 녹음을 글자로 바꾸는 중이에요 / 녹음을 찾는 중이에요(통화 뒤 10분) / 녹음 없음", "개인 통화" |
| 정리 상태 | "정리하고 있어요", 6시간 넘으면 "정리가 늦어지고 있어요", 말소리가 없던 녹음은 "녹음에서 말소리를 찾지 못했어요"(버튼 없음) |
| 상세 | 제목은 상대 이름(누르면 사람 화면) + 날짜·시각·길이 + 전화 걸기 버튼, "○○ 님 보기 ›", "업체 보기 ›" → 정리 못 한 통화는 앰버 상자와 [다시 정리하기](적용 실패는 "정리 결과를 적용하지 못했어요") → "요약"(요약 + 중요한 내용) → "이 통화에서 생긴 체크할 일"(열린 것은 [틀렸어요] [다 됐어요], "제가 하기로/상대가 하기로", 인용 ‘…’, "확인 필요" 배지) → [통화 내용 전체 보기]/[접기](자막, 7일 보관) |

### 3.3 체크할 일 (체크 탭)
| 요소 | 내용 |
|---|---|
| 머리 | "체크할 일", "n개 남았어요" |
| 묶음 | 끝났는지 확인해 주세요 / 오늘 요청한 일 / 어제 요청한 일 / 그전에 요청한 일(빈 묶음은 숨김). 14일 넘은 것은 "오래된 일 n개 보기 ›"로 접힘 |
| 행 하나 (모든 화면 공통) | ① 업체 배지, "확인 필요" 배지, 상태 알약(끝났는지 확인/진행 중/기다리는 중) ② 제목(META와 겹치는 "○○ 님께"는 뺌) ③ META "김민수 님, 오늘 요청"(이름을 누르면 사람 화면) ④ "AI 메모: …" ⑤ [틀렸어요] [다 됐어요]([틀렸어요]는 AI·새벽 정리가 만든 일에만, 직접 적은 일에는 없음) |
| 누르기 | 통화에서 생긴 일만 그 통화를 연다. 직접 적은 일·새벽 팔로업은 눌림 표시 없음 |
| [다 됐어요] | 누르는 즉시 흐려지고 "끝낸 일로 옮겼어요 [되돌리기]" 띠 |
| [틀렸어요] (v3.9) | 잘못 뽑힌 일(약속이 아닌데 생긴 일, 남의 일, 숫자가 틀린 일)을 사유 없이 한 탭으로. 누르는 즉시 흐려지고 "틀린 일로 뺐어요 [되돌리기]" 띠. 열린 목록에서 빠지고 "끝낸 일 보기"에 "틀린 일로 뺌"으로 남아 나중에도 되돌릴 수 있다. 통화 상세에는 그 일 아래 "틀린 일로 뺌". 같은 통화를 다시 정리하거나 말만 조금 바꾼 같은 일이 와도 다시 생기지 않는다(14일). 앱 밖으로는 건수(하트비트)와 그 일(새벽 정리 state, 비공개 우편함 — 다음 보고에서 빼고 다시 만들지 않음)만 나간다. 버튼 둘이 한 줄에 안 들어가면 위아래로 나뉜다 |
| 아래 | "끝낸 일 보기 (7일) ›"(v3.9: [틀렸어요]로 뺀 일도 "틀린 일로 뺌"과 [되돌리기]로 여기 있다 — 잘못 눌렀으면 여기서 되돌린다), [+ 직접 적기](제목과 업체를 골라 저장) |

### 3.4 업체와 사람 (업체 탭)
| 요소 | 내용 |
|---|---|
| 목록 | "업체 n곳, 최근에 통화한 순서예요", 찾기 "업체, 사람 찾기". 행: 공종 배지, 업체명, "체크할 일 n개, 어제 마지막 통화" |
| 업체 없는 사람 | "업체 없는 사람 (우리 직원 등)" 절, 행을 누르면 사람 화면 |
| 업체 상세 | 업체명 + "공종 철근" + 전화 걸기(가장 최근 사람), [업체 이름 고치기] → 업체 메모 → 진행 중인 일 (n)(있을 때만) → 사람 (n) → 체크할 일 (n) → 최근 통화(이름을 누르면 사람 화면) |

### 3.5 사람 (v2.8부터, 이름을 누르면 어디서나)
머리: 이름, "탄탄이엔씨 대표"(우리 직원이면 "우리 직원 공무"), 둥근 [전화 걸기] [문자 보내기](번호는 화면에 쓰지 않음). 같은 번호를 여럿이 쓰면 "이 번호를 쓰는 사람: 박영희 대리 외 1명"과 사람 칩.
순서: 마지막 통화("11월 4일 (화) 오후 2:10, 3분 12초, 받은 전화") → 체크할 일 (n)(전부, [다 됐어요]) → 진행 중인 일 → 최근 통화와 문자(10건) → 글자 링크 [이름 고치기](옛 이름은 별칭으로 남아 같은 오인식도 이 사람에 이어짐), [이 번호는 개인으로 두기](확인 시트, 설정에서 되돌림).

### 3.6 설정
머리 "설정, 처음 설정한 것도 여기서 언제든 바꿀 수 있어요". 주황 신호등이 하나라도 있으면 "지금 상태"가 맨 위로 온다.

| 묶음 | 내용 |
|---|---|
| 지금 할 일과 진행 상황 | 녹음 공백 한 줄("녹음이 들어오지 않고 있어요. 아래 지금 상태에서 볼게요 ›"), 처음 설정(3.7), 지난 통화 정리("녹음 120개 중 59개 남음", 쉬는 이유 "잠시 쉬고 있어요/충전기에 꽂으면 이어서 정리해요"), 음성 인식 모델("받는 중 42% (241MB / 574MB)" 막대, [다시 받기]). 할 일이 없으면 "지금 할 일이 없어요. 모두 잘 되고 있어요 ✓" |
| 연결 | 녹음 폴더, 문자, 통화기록, 통화 끝 알아차리기(전화 상태). 메일(IMAP) 연결은 v3.7에서 지움. 각각 "허용됨 ✓ …" 또는 이유 + 버튼, 막혔으면 [앱 정보 열기]와 제한된 설정 안내 |
| 통화 카드 | 다른 앱 위에 표시 허용, 스위치 "전화 올 때", "전화 걸 때", "아직 정리된 통화가 없는 번호도"(기본 끔), "잠금 화면에서도 이름과 한 줄 보기"(기본 켬), [카드 위치 처음으로]. 선택 제안 "거는 전화에 번호를 더 빨리 알기"는 v3.9에서 맨 아래 "관리"로 옮김 |
| 정리 | 정리 동의 스위치(녹음은 폰 밖으로 안 나간다는 설명), 알림 시각 "저녁 통화 정리"(15~23시, 기본 19시), "녹음이 없는 통화는 바로 알림"(v3.9, 예전 "통화마다 알림"과 같은 스위치 — 아래 "다른 통화는 저녁 통화 정리 알림 하나에 모아서 알려 드려요."), "새 버전은 자동으로 설치"(+ 필요하면 [설치 허용]), 내 정보(이름, 회사와 현장, 직책), 개인으로 둔 번호(되돌리기) |
| 아침 보고 (v3.5) | 스위치 [카카오톡으로 받기](기본 켬). 연결 전: "카카오톡을 연결하면 매일 아침 5:30에 나와의 채팅으로 어제 통화 정리와 오늘 챙길 일을 보내요." + [카카오톡 연결하기]. 연결 뒤: "연결됨, 매일 5:30에 보내요", "오늘 5:30에 보냈어요", [지금 보내 보기](시험, 하루 한 번), [연결 끊기]. 풀렸으면 "카카오톡 연결이 풀렸어요" + [다시 연결]. 그 아래 "이음 알림" 시각 "아침 체크할 일"(4~11시, 기본 6시) |
| 상태와 도움 | 지금 상태 신호등 여섯 줄(녹음 가져오기, 글자로 바꾸기, 통화 정리, 알림, 업데이트, 통화 카드: 초록 "정상" 또는 앰버 이유와 할 일 한 문장, 빨강 없음, 줄을 누르면 고칠 곳으로), 앱 버전과 업데이트([지금 확인 ›], 받는 중 %, [지금 설치]/[지금 업데이트], 실패 이유), 음성 인식 모델, 현장 상황 메모 보기, [문제 알리기] |
| 관리 (v3.9, 맨 아래, 기본 접힘) | "관리하는 분이 쓰는 기능이에요. 평소에는 열지 않아도 돼요." + [관리 항목 보기 ›]. 펼치면 예전 그대로: 처리한 통화와 [기다리는 통화 다시 정리하기], [상대 카드 다시 만들기], [합친 사람 되돌리기], "거는 전화에 번호를 더 빨리 알기"([허용하기]/[괜찮아요]), (시험 빌드) [속도 측정], "골든 측정 ›"(자막 정확도 재기). 앱을 다시 켜면 접혀 있다 |

### 3.7 처음 설정 (설정 맨 위, 막히지 않음)
"처음 설정 남은 n단계" → "다음 할 일: ○○" 큰 제목 → 이유 문장 바로 아래 버튼 하나. 선택 단계에는 "선택 단계예요. 하지 않아도 이음은 그대로 돌아가요."와 [나중에 할게요](설정에 남음). 첫 실행에만 펼쳐 보인다.

| 구분 | 단계 (버튼) |
|---|---|
| 필수 | 녹음 폴더 연결 [녹음 폴더 고르기] → 정리 동의 [동의하고 켜기](동의 즉시 모델 574MB를 어떤 연결에서든 받기 시작) → 통화기록 읽기 허용 → 통화가 끝난 걸 바로 알아차리기 [전화 상태 허용] → 알림 허용 [알림 허용하기](두 번 거절 뒤 [알림 설정 열기]) → 배터리 제한 풀기 [제한 풀기] → (v3.9 새 설치) 통화 화면 위에 이음 카드 보기 [카드 보기 허용](돌아왔는데 안 켜졌으면 "목록에서 '이음'을 찾아 스위치를 켜 주세요"를 굵게 + [다시 열기], [나중에 할게요] 없음) |
| 선택 | 문자 읽기 허용 → (v3.9 전에 설정을 마친 폰만) 통화 화면 위에 이음 카드 보기 → 새 버전을 저절로 설치하기 [설치 허용] |

통화 카드는 실측에서 가장 잘 돌아가는 기능이라 v3.9부터 새 설치에서는 필수 단계다. 이미 설정을 마친 폰(아내 폰)은 업데이트해도 예전처럼 선택 단계로 남아 홈에 새 "확인할 일"이 생기지 않는다.

거는 전화 역할은 처음 설정에 없다(v3.4부터 카드가 역할 없이 뜸). 거부해도 다음 단계로 간다.

### 3.8 알림
| 알림 | 시각 | 제목 / 내용 | 누르면 |
|---|---|---|---|
| 녹음 없는 통화 (v3.9, 예전 "통화마다") | 통화 끝 2분 뒤 녹음을 찾았는데 없을 때만 | "김민수 대표와 통화 / 이 통화는 녹음이 없어 정리할 수 없어요. 메모를 남기면 체크할 일에 넣어 드려요" + [메모 남기기](한 줄 → 체크할 일). 여러 개면 한 묶음 "통화 알림 n개 / 확인할 통화 n건". v3.9부터 녹음이 있는 통화는 통화마다 알림을 띄우지 않는다: "정리하고 있어요/정리됐어요/늦어지고 있어요"는 저녁 정리 알림 한 통과 전화가 올 때의 카드, 아침 카톡이 알린다. 녹음 없는 통화만 남긴 이유: 요약도 저녁 보고 줄도 생기지 않아 다른 곳에서 말해 주지 않고, 메모는 통화 직후에만 쓸모가 있다. 연결 안 된 발신은 알림 없음. 녹음 꺼짐 판정 중에는 통화별 알림 대신 홈 한 줄. 폰 알림 설정의 채널 이름은 "이음 녹음 없는 통화" | 그 날 통화 |
| 저녁 정리 | 19:00(설정) | "녹음 n개 중 정리 m개, 새 체크할 일 k개", 펼치면 통화마다 "오후 2:10 김민수, 첫 문장"(7줄까지 + "외 n개"), 정리 중이면 ", 아직 정리 중인 통화가 n건 있어요". 통화는 있었는데 녹음이 0이면 "오늘은 녹음된 통화가 없어요" | 그날 통화 |
| 카톡 아침 보고 (v3.5) | 05:30 | 카카오톡 "나와의 채팅"에 그림 한 장(보고서 전체) + 글 한 통(오늘 챙길 일 4개), 3.11 | 메시지의 [이음에서 보기]: 통화(어제) 또는 체크 |
| 아침 보고 | 06:00(설정) | "체크할 일 n개", 첫 줄 "지금 할 일: [업체] 제목, 오늘 요청" + [다 됐어요](누르면 다음 항목으로, 마지막엔 "체크할 일을 다 끝냈어요"), "끝났는지 확인", "확인 필요", "진행 중, ○○: 현황"(3줄까지), "늦게 정리된 통화 n건", "새 버전 설치가 기다리고 있어요". 순서는 확인 필요 → 오늘·어제 요청 → 나머지(최근 먼저). 카톡이 간 날은 첫 줄 "카카오톡 나와의 채팅에 아침 보고를 보냈어요"로 **소리 없이** 오고, 업데이트 대기나 늦게 정리된 통화가 있으면 소리 있게 | 체크할 일 |
| 자가 진단 | 저녁 보고 작업 뒤 | 하나면 그 제목, 여럿이면 "이음에서 살펴볼 일이 n가지 있어요": 통화 녹음이 꺼져 있는 것 같아요 / 통화가 일부만 녹음되고 있어요 / 녹음 폴더 연결이 풀렸어요 / 통화 글자 바꾸기가 밀려 있어요 / 음성 인식 모델을 다시 받아야 해요 / 정리가 늦어지고 있어요 / 이음 저장 공간이 거의 찼어요 / 분석이 n시간 안 돌았어요 / 새 버전이 하루 넘게 설치되지 않았어요 / 새 버전 설치가 기다리고 있어요 / 아침 보고가 카카오톡으로 안 갔어요(v3.5) | 설정 |
| 새 버전 | 받았을 때(누르지 않고 설치되지 않을 때) | "이음 새 버전이 준비됐어요" + version.json의 notes(= `docs/UPDATE_NOTE.txt` 첫 줄), 설치 확인이 필요하면 "눌러서 설치를 마쳐 주세요". 알림을 지워 버렸어도 하루가 지나면 다시 뜬다(v3.5) | 설치 |

모든 보고 알림은 BigText로 줄을 자르지 않는다. 잠금 화면에는 "잠금을 풀면 내용이 보여요"(녹음 없는 통화 알림은 "확인할 통화").

### 3.9 통화 카드 (v3.0, v3.4에서 모든 전화로)
| 순간 | 카드 |
|---|---|
| 벨 울림 | 펼친 카드(화면 높이 34% 안, 아래 끝은 72% 위, 기본 38% 지점, 끌어 옮기면 기억) |
| 받음 | 3초 뒤 위쪽(8~20%) 띠로 접힘 "김민수 대표, 견적서 보내기, 어제 요청". 누르면 펼침. 보여 줄 일이 없으면 띠 대신 사라짐 |
| 걸 때 | 위쪽 25% 안에 펼친 채 3초 → 띠 |
| 끊음 | 사라진다(v3.9부터 녹음이 있는 통화는 저녁 정리 알림에서 이어짐, 녹음이 없으면 그 통화 알림) |
| 통화 대기 | 둘째 벨이 오면 카드를 숨기고 다음 통화 끝까지 아무것도 안 띄움 |
| 개인·제외 번호 | 아무것도 안 뜸 |

카드 내용(5줄 이하, 위부터): [접기][닫기] → **첫 줄**(20sp 굵게, 2줄까지, 띄어쓰기에서 끊음): ① 약속 날짜가 지났거나 7일 안인 열린 체크할 일(날짜는 순서에만 쓰고, 글은 v3.5부터 상태 "문자로 끝난 것으로 보여요"·"끝났는지 확인"·"어제 요청"; "금요일까지"·"n일 지났어요"는 안 씀) ② "확인 필요"인 일(배지 앞에) ③ 14일 안 지난 통화 요약 첫 문장 ④ 진행 중인 일 ⑤ "3일 전 통화, 30일간 5번" → "김민수 대표, 탄탄이엔씨, 3일 전" → "체크할 일 … 외 n개" → "진행 중인 일 …". 전화번호와 자막은 쓰지 않고 금액·날짜·수량은 보인다. 정리된 통화가 없는 번호는 "아직 정리된 통화가 없는 번호예요" + 통화기록 한 줄(스위치를 켰을 때만).

### 3.10 잠금 화면
- 잠긴 폰에 벨이 오면 카드 창과 내용 있는 알림을 함께 띄우고, 잠금을 풀면 알림을 지운다.
- "잠금 화면에서도 이름과 한 줄 보기"가 켜져 있으면(기본) 이름, 업체, "체크할 일: …" 한 줄(번호·금액·자막 없음). 꺼져 있으면 "이음 통화 카드 / 잠금을 풀면 카드가 보여요".
- 보고 알림과 녹음 없는 통화 알림은 잠금 화면에 내용 없이(3.8 끝).

### 3.11 카카오톡 아침 보고 (v3.5)
- **아내가 보는 것:** 매일 아침 5:30쯤 카카오톡 "나와의 채팅"에 이음 보고가 두 통 온다. 첫 통은 **그림 한 장**에 보고서 전체(제목 "[이음 아침 보고] 11/7(금)", "어제 통화 7건, 새 체크 3개, 오늘 챙길 일 5개", 어제 정리 번호 목록, 오늘 챙길 일, 진행 중인 일, 확인이 필요한 것)가 큰 글씨로 들어 있고, 누르면 크게 보인다. 둘째 통은 **글**로 "오늘 챙길 일" 상위 4개라 알림 미리보기에서 바로 읽히고 복사할 수 있다. 어느 통이든 [이음에서 보기]를 누르면 앱의 어제 통화나 체크 탭이 열린다.
- **글 모양:** 보고 형식(제목 + 짧은 번호 목록, "견적서 금요일에 보내기로" 같은 명사형), 업체·사람 단위로 묶음, 약속·금액·날짜가 있는 일 먼저. 체크할 일에는 "어제 요청"과 뒤에 확인된 상태("문자로 답 받음")만 붙고 "언제까지", "지났어요"는 없다.
- **할 일:** 처음 한 번 설정 › 아침 보고 › [카카오톡 연결하기]. 그다음은 아무것도 누르지 않는다. 원하면 [지금 보내 보기]로 하루 한 번 미리 받아 볼 수 있다.
- **안 올 때:** 새벽 정리가 늦으면 6시까지 기다렸다가 폰이 가진 체크할 일로 짧은 보고 한 통을 보낸다. 카톡이 실패하면 이미지 대신 글 몇 통으로 다시 보내고, 그래도 안 되면 6시 이음 알림이 평소처럼 소리 내어 온다. 9시가 지나면 그날 카톡은 보내지 않는다. 연결이 풀리면 설정 신호등 "알림" 줄과 저녁 자가 진단이 알려 준다.
- **받는 사람과 개인정보:** 아내 본인 카카오 계정의 "나와의 채팅"에만 간다(남편이나 다른 사람에게는 안 감). 이름·업체·요약·체크할 일은 카카오 서버를 거치고, 보고 그림은 카카오 서버에 주소만 알면 열리는 형태로 100일 남는다(주소는 길고 무작위). 전화번호·통화 자막·문자 원문은 넣지 않는다.

## 4. UX 설계 원칙

### 4.1 핵심 원칙
1. **버튼 없는 자동화** — 설정을 마친 뒤 할 일은 "읽기"와 [다 됐어요]뿐. 하루 누름은 아침 0~1, 전화 올 때 0, 저녁 0~1.
2. **홈은 요약, 이동은 아래 탭** — 홈은 이야기와 먼저 볼 체크할 일 같은 요약만. 숨은 메뉴·햄버거 없음. 뒤로는 상세 닫기 → 홈 → 종료, 지금 탭을 다시 누르면 목록 맨 위.
3. **설정에서 한 번에 한 단계** — 지금 할 단계 하나만 크게, 막혀도 다음으로. 홈에는 할 일이 있을 때만 한 줄.
4. **누르면 바로 반응** — 누르는 순간 바뀌거나 "○○하는 중이에요", 두 번 눌러도 한 번만.
5. **근거를 보여 준다** — 체크할 일에 통화 원문 인용, 불확실하면 "확인 필요".
6. **AI는 제안, 사람이 결정** — 완료·이름 고치기·합치기 되돌리기는 사람만.
7. **알림만 읽어도 된다** — 아침 보고는 카카오톡과 앱 알림에서 앱을 열지 않아도 전부 보이고, 앱 알림에서 바로 끝낼 수 있다.
8. **스스로 말한다, 지키지 못할 약속은 하지 않는다** — 안 되는 것은 이유와 할 일을 한 문장으로. 녹음 없는 통화에 "정리하고 있어요"라고 하지 않는다.
9. **개인정보** — 녹음은 폰 안에만, 자막은 14일 뒤 비움(요약은 남음), 화면에 전화번호를 쓰지 않음, 통화 카드 창은 캡처 차단(앱 화면 캡처는 10/30 결정으로 허용).

### 4.2 화면 흐름
```
아래 탭: 홈 │ 통화 │ 체크 │ 업체 │ 설정
홈 ─ "설정에서 확인할 일이 있어요" → 설정의 그 줄
   ─ 오늘 통화 이야기 / 메모 → 통화(상세)
   ─ 먼저 볼 체크할 일 → 그 통화, 이름 → 사람
통화 ─ 통화 상세 ─ 사람 / 업체 / 통화 내용 전체
체크 ─ 행 → 그 통화, META 이름 → 사람
업체 ─ 업체 상세 ─ 사람 ─ 이름 고치기(시트)
설정 ─ 지금 상태(주황이면 맨 위) ─ 지금 할 일과 진행 상황 ─ 연결 ─ 통화 카드 ─ 정리 ─ 아침 보고 ─ 상태와 도움 ─ 관리(접힘, v3.9)
알림: 녹음 없는 통화 → 그날 통화 / 저녁 → 그날 통화 / 아침 → 체크 / 자가 진단 → 설정
카톡 아침 보고: [이음에서 보기] → 어제 통화 또는 체크
통화 화면 위: 이음 카드(벨·걸 때) → 띠 → 끊으면 사라짐(녹음 없으면 그 통화 알림)
```

### 4.4 글 규칙 (CI `tools/check_ui_rules.py`와 화면 시험이 검사)
- **읽는 글 18sp 이상.** 16sp는 META 줄(누가, 언제)과 배지만(`CallUi.meta`), 새 `caption(` 사용은 경고.
- **가운데 점(·) 금지** — 쉼표나 띄어쓰기, 자연스러운 문장으로("김민수 대표, 탄탄이엔씨, 3일 전").
- **말줄임표(…, ...) 금지, 자르지 않는다** — 목록은 첫 문장만(`firstSentence`), 카드는 띄어쓰기 경계에서. 나머지는 눌러서.
- **"할 일"이 아니라 "체크할 일"** — 상대가 할 일도 체크할 일. 기한 대신 **요청 날짜**("오늘 요청"), "기한"이라는 낱말과 급박한 표시를 쓰지 않는다.
- **숫자는 녹음 기준** — "녹음 n개 중 m개 남음". 통화기록 전체 수는 검증용으로만(하트비트·워치독·검증 작업). 통화 목록에 모든 통화가 한 줄씩 보이는 것은 그대로.
- **지키지 못할 약속 금지** — 녹음이 없는 통화에 "정리하고 있어요", "저녁 보고에 넣어 드릴게요"를 쓰지 않는다. 늦으면 늦다고 말한다.
- 영어 상태값(FAILED 등)·전문용어 노출 금지, "~해요" 체. 루틴이 쓴 이야기도 폰이 가운데 점·말줄임표를 걷어 낸다.

## 6. 아직 남은 UX 과제 (11/10 기준 — 전체 미해결 목록의 원본은 [DESIGN.md](DESIGN.md) 11절, 여기에는 화면·문구만)

0. **통화 카드가 어떤 날은 하나도 안 뜬다**(11/7, 11/10 오전 — 원인 조사 중). 그날 아내에게는 소리 없는 알림만 남고, 설정의 신호등은 초록이다 → v3.6.1.
1. **낮 통화가 저녁에 안 보인다.** "충전 중에만"이 켜져 있어 19시 알림 제목이 "녹음 n개 중 정리 0개", 홈은 "오늘은 아직 정리된 통화가 없어요"가 된다. 다음 날이 되면 어제 통화는 홈에서 사라진다. 통화 목록과 통화별 알림은 "충전하면 이어서 정리해요"로 사실대로 말한다. v3.7에서 아침 보고를 채우고(빠진 건수도 적음) v3.9에서 낮 처리를 되찾는다.
2. **아침 카톡이 빠진 통화를 말하지 않는다.** "어제 통화 14건"만 보이고 아직 글자로 바꾸는 중인 통화 수가 없다 → v3.7 "어제 통화 14건을 정리했어요. 9건은 아직 글자로 바꾸는 중이에요".
3. **아침 "늦게 정리된 통화"가 낮 통화를 세지 못한다**(버그), 저녁 "충전하면 n개를 이어서 정리해요"의 n에 지난 대기분이 섞인다.
4. **설정:** 첫 실행 설정이 주황 경고로 시작한다. 관리자용 기능(다시 정리, 카드 다시 만들기, 합친 사람 되돌리기, 골든 측정, 역할 요청)은 v3.9에서 맨 아래 "관리"로 접었고, 통화 카드는 새 설치에서 필수 단계가 됐다. 메일 묶음은 v3.7에서 삭제. 3주치 `use`로 "한 번도 안 열린 화면·안 눌린 알림"을 지우는 판단은 아직이다.
5. **남은 문구:** "끝나기까지 약 1시간 안"(지키지 못할 약속), 신호등 "위 ○○ 묶음에서"(주황이면 신호등이 맨 위라 방향이 틀림), 자가 진단의 "와이파이에 연결한 뒤"(11/5 "연결 무관" 결정과 어긋남), "AI 메모" → "이음 메모" 미정.
6. **쓰이는지 모른다.** 카드 띠를 눌러 펼친 횟수 0, 앱 열기·알림 누름·[다 됐어요]는 세지 않는다 → v3.7 사용 숫자, v4.0에서 아내에게 5문항.
7. **S26 실기기 확인 전** — 잠금 위 카드 창, 삼성 "통화 팝업" 때 위치, 통화 중 버튼을 가리는지, 1.3배 글자(`docs/REAL_DEVICE_CHECKLIST.md`). 카드 위치 상수와 첫 줄 글자 수는 실측 없이 둔 기본값.
8. 자막 오인 교정 표시(`corrected`)는 저장만 하고 화면에 아직 없다(v3.9).
