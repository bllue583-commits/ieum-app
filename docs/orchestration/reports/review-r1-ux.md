# R1 화면·UX·활용성 검토 (Opus, 11/5 17시, 기준 157ffab) — 점수 6/10
총평: 화면 품질은 크게 좋아짐(단일 Activity, 즉시 반응, 빈·오류 상태, 11/5 UI 보고서 31건 중 27 닫힘·4 부분). 그러나 실제 폰 상황(녹음 0, 열린 일 0)을 앱이 "정상(초록)"·"정리하고 있어요"로 보여 줌 — 녹음이 안 되고 있다는 사실을 어디서도 말하지 않음. 처음 설정 10단계는 한 줄로만 진행(막히면 뒤 단계 불가, 건너뛰기 없음). 잠금 화면 수신에는 카드 내용이 거의 안 보임.
## 발견
1 치명 신호등 "녹음 가져오기"가 폴더·발견 시각만 보고 초록(StatusLights.kt:56-61); "자동 녹음 켜기" 안내 0건 → 24시간 업무 통화 n건 중 녹음 0이면 주황 + 홈 배너, 문구 "삼성 전화 앱 › 설정 › 통화 녹음 › 자동 녹음".
2 높음 녹음 없는 통화도 12시간 "녹음을 글자로 바꾸는 중"(CallsScreen.kt:61-65) → 자막 작업 ±2분 맞을 때만; 없으면 10분 "녹음을 찾는 중" 뒤 "녹음 없음".
3 높음 통화 뒤 알림이 녹음 여부를 안 봄(CallFollowupNotice.kt:77-96), "저녁 보고에 넣어 드릴게요"는 지킬 수 없음(CallDigestWork.kt:32-38) → aftercall 발견에서 녹음 잡혔을 때만; 없으면 "녹음이 없어요, 메모만" + [메모 남기기].
4 높음 저녁 알림 통화 수가 기록만 셈(CallDigestWork.kt:38) vs 홈 callCount → 같은 기준, "통화 30건, 녹음된 통화 0건".
5 높음 처음 설정: 다음 단계 하나만 열림(HomeScreen.kt:303-314), 거절하면 영원히 남고 카드 안 사라짐(:292) → [나중에 할게요], 모델은 동의 뒤 Wi-Fi에서 자동, 막지 않는 진행 줄.
6 높음 잠금 폴백 알림 publicVersion이 "잠금을 풀면 카드가 보여요"뿐(CallCardOverlay.kt:263-273) → 설정 "잠금 화면에서도 이름과 한 줄 보기"(기본 켬): 이름·업체·체크 1줄(번호·자막 없음).
7 높음 홈: 처음 설정·처음 정리 카드가 숫자 아래라 "먼저 볼 체크할 일"이 첫 화면 밖(HomeScreen.kt:292-355, 스크린샷 1·9) → 한 줄 배너로 접기.
8 중간 처음 설정 이유 문장이 16sp 회색(HomeScreen.kt:262,279,295,308-310), 폴더·모델 단계 이유 없음, "6/10"+"1단계" 혼란 → 이유 19sp INK 버튼 위, "다음 할 일, 남은 n단계".
9 중간 Android 11+ ACTION_MANAGE_OVERLAY_PERMISSION은 전체 앱 목록(HomeScreen.kt:443-446) → "목록에서 '이음' 찾아 켜기" 안내 + [다시 열기].
10 중간 18sp 규칙 구멍: CallUi.text가 16/15 최소값 태그를 스스로 달아 CallUiSeniorTest 통과(CallUi.kt:269, CallUiSeniorTest.kt:30), check_ui_rules는 크기 안 봄 → 16sp는 CallUi.meta()만 허용.
11 중간 기기 증거: 9_home_large가 실제 1.3배인지 의심(CallPipelineDeviceTest.kt:213-215, 본문 6%만 큼), 어두운 모드 샷 없음, 카드 0바이트 → fontScale 확인 뒤 재생성, night 샷, debug만 FLAG_SECURE 해제 또는 Robolectric 카드 샷 4종.
12 중간 카드 윗변 38%+높이 40% → 1.3배에서 78%까지, 삼성 받기·거절 쓸어넘기기(≈80%) 근접(CallCardOverlay.kt:53,198,206-210) → 수신 중 높이 34%, 아래 끝 ≤72%.
13 중간 설정 신호등 알림 판정이 권한만(SettingsScreen.kt:367) → NotifyAsk.allowed.
14 중간 설정 [모델 받기] 토스트만(SettingsScreen.kt:289-291) → ModelWish·퍼센트.
15 중간 체크 제목 이름 중복("김민수 님께 … / 김민수 님, 오늘 요청", TasksScreen.kt:37-50) → META에 이름 있으면 접두 제거, 지시문 v6 10번 적용.
16 중간 아침 알림 [다 됐어요]가 어느 줄인지 불명(CallDigestWork.kt:44-50,225-230) → "지금 할 일:" 말머리, 진행 중인 일은 아래로.
17 낮음 카드 "마지막 통화"가 길이 대신 방향(CallCardView.kt:78-86), 요약 40자 하드 컷(ContactCards.kt:209-212).
18 낮음 통화 상세 체크할 일에 [다 됐어요] 없음(CallsScreen.kt:351), "전체 보기" 토글 접기 표시 없음(:360).
19 낮음 설정 신호등이 맨 끝(SettingsScreen.kt:222-273) → 주황이 있으면 맨 위로.
20 낮음 업체 검색어가 상세 열면 지워짐(CompaniesScreen.kt:55).
