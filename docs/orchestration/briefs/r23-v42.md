## r23-1 배터리 예산을 실제 상한으로

- 왜 넘는지 먼저 코드에서 확인한다(추정: 예산에 닿기 직전에 시작한 조각이 끝까지 돈다 / 배터리 실행 분을 조각이 끝난 뒤에 더한다 / 충전기에서 내려온 뒤의 실행이 배터리로 세어진다). 원인을 보고에 적는다.
- 고친 뒤: 하루 배터리 실행 분이 `budgetMin`을 **조각 하나의 예상 시간 이상** 넘지 않는다. 방법은 판단에 맡긴다(예: 남은 예산이 최근 조각 중앙값보다 적으면 시작하지 않음). 끝난 조각을 버리지 않는다. 충전 중 실행은 건드리지 않는다.
- 시험: 예산 18분을 쓴 상태에서 5분짜리 조각을 시작하지 않는다 / 2분 쓴 상태에서는 시작한다 / 충전 중에는 예산과 무관.
