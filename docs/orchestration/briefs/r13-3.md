## r13-1에서 넘어온 일 (보고서 `docs/orchestration/reports/feature-r13-v33-r1.md`)
1. `screens/TasksScreen.kt`의 `CheckRows.UNSURE`, `unsureBadge`, `stateWords`, `shortTitle`를 `CallUi`로 옮긴다.
   - 앰버 `AMBER_RAIL` 바탕에 #191F28 글자, 18sp 굵게.
   - TasksScreen은 그것을 부르게 바꾼다. 이 일 때문에 TasksScreen을 고치는 것은 허용한다.
2. 통화 상세(CallsScreen)의 체크할 일에 "확인 필요" 배지를 붙인다.
3. 설정 화면 글과 스위치
   - 스위치 글 "전화부에 없는 번호도"를 "아직 정리된 통화가 없는 번호도"로 바꾼다.
   - 새 스위치 "잠금 화면에서도 이름과 한 줄 보기"를 넣는다(`PipelineSettingsKeys.LOCK_SCREEN_DETAIL`, 기본 true).
4. 골든 측정 진입 링크(3.2-4)
   - 설정 "상태와 도움" 아래 숨김 한 줄이다. r13-2가 만드는 Activity라 이름이 아직 정해지지 않았다.
   - 링크는 `kr.callbrief.screens.GoldenActivity`를 이름(문자열)으로 찾는다. 클래스가 없으면 줄을 숨긴다.
   - 실제 이름은 통합 때 오케스트레이터가 맞춘다.
