# r15-2 지시문: 새벽 정리 v7 (v3.5, 기준 `feature/r15-v35` a52801d)

## 할 일
1. `docs/routines/tidy.md`를 v7로: 9번 뒤에 **9-1 "아침 보고서"** — 1절 JSON 형식으로 `report/YYYY-MM-DD.json`(KST 오늘)을 쓴다. 어제 기록은 state의 records와 매시간 결과 요약에서. `yesterday` 업체·사람 단위 묶음 최대 8줄(약속·금액·날짜 있는 것 먼저, 개인 통화 제외), `today` 열린 체크할 일 중 오늘·어제 요청과 확인 필요 먼저 최대 8줄, `status`는 이행 흔적이 있으면 상태 글·없으면 빈 문자열(완료 처리 안 함), `since`는 요청 날짜 표현, `inProgress` 3줄·`check` 3줄. 금지: 가운데 점·말줄임표·영어 상태값·"기한"·"지남"·"까지"로 끝나는 기한 표현·전화번호. 한 줄 60자. `python3 tools/report_check.py report/<날짜>.json` 통과 뒤 커밋, 30일 지난 report 파일 삭제. 지시문 버전 표기·`tidyVersion` 갱신 방식은 기존 v6 표기를 따른다. 시작 시각 표기(05:16)는 04:46으로.
2. `tools/report_check.py`(신설, 표준 라이브러리만): 형식·필드·줄 수·한 줄 60자·금지어·전화번호(한국 번호 패턴) 검사, 실패면 종료 코드 1과 이유. `tools/test_report_check.py`(정상·넘침·전화번호·영어 상태값·빈 어제).
3. `docs/routines/self-report.md`(있으면)와 자가 보고에 `reportWritten`.
4. `tools/inbox/watchdog.py`·`test_watchdog.py`: 규칙 2개 — "아침 보고서가 안 만들어졌어요"(KST 05:30 지났는데 `report/<오늘>.json` 없음), "카카오톡 보고가 안 갔어요"(하트비트 `kakao.linked=true`인데 `kakao.lastSentMs`가 KST 09:00 지나도 오늘이 아님, 2일 연속이면 이슈). 하트비트 키는 키 커밋 `PhoneStatus.putV35` 참고: `kakao{linked,sent,failed,lastSentMs,error}`, `report{day,source}`.

6. release-apk가 `tools/`를 우편함으로 복사하는 목록에 `report_check.py`가 들어가야 하면 보고서에 적기(워크플로는 오케스트레이터).
