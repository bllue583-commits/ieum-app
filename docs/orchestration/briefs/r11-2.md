# r11-2 이음 카드 화면 (v3.0)

공통 지침 `docs/orchestration/worker-brief.md`를 먼저 읽고 따르세요. 브랜치 이름: `feature/r11-v30-r2`. 기준은 `feature/r11-v30`(v2.9 완성본).

설계: `docs/DESIGN_V3.md` 7.1(카드 내용·동작 표), 7.2(창 결정), 7.3 **r11-2**.

## 담당 파일
- `pipeline/call/CallCardOverlay.kt`(신설, object): `show(context, phoneKey:String?, state: CallSession.State)`, `collapse()`, `expand()`, `hide()`. `WindowManager.addView`, `TYPE_APPLICATION_OVERLAY`, `FLAG_NOT_FOCUSABLE or FLAG_NOT_TOUCH_MODAL or FLAG_LAYOUT_IN_SCREEN`, 터치는 카드 영역만. 오버레이 권한이 없거나 화면이 잠겨 있으면(`KeyguardManager.isKeyguardLocked`) 헤드업 폴백 알림(채널 `ieum.calls.card` "이음 통화 카드", 소리 없음, BigText 3줄)을 띄우고, `ACTION_USER_PRESENT`를 받으면 카드로 전환. 2단계 그리기: 먼저 이름 줄만, 50ms 안에 나머지(자료는 `ContactCards.get(phoneKey)` — v2.8 r9-2의 API, 보고서 `docs/orchestration/reports/feature-r9-v28-r2.md` 참고).
- `pipeline/call/CallCardView.kt`(신설): 코드로 그린 View(`CallUi` 토큰, 어두운 모드 따라감, `FLAG_SECURE`). 내용(위부터): 이름과 직책(STRONG 20) · 업체와 공종(META) · "마지막 통화 어제 오후 3시, 2분"(META) · "지난 통화" 요약 첫 문장(BODY 18) · "체크할 일" 최대 3줄(제목, "어제 요청") · "진행 중인 일" 1줄 · 오른쪽 위 [접기] [닫기]. 번호와 자막은 쓰지 않음. 높이 화면 40% 이하, 세로 38% 지점, 손잡이로 끌어 옮기면 위치 기억(설정 키 `CARD_POS_Y` — r11-1과 같은 이름). 받으면(OFFHOOK) 3초 뒤 띠로 접힘("김민수 대표, 지난 통화: 견적서 금요일까지"), 띠를 누르면 펼침. 모르는 번호(카드 없음)는 설정 "전화부에 없는 번호도"가 켜졌을 때만 "전화부에 없는 번호예요" + 최근 문자 한 줄. 개인·제외 번호는 아무것도 안 띄움.
- 테스트 태그 `card_*`. `CallUiSeniorTest` 규칙(18sp 이상, 대비 4.5:1, 가운데 점·말줄임표 금지).
