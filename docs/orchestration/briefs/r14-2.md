# r14-2 카드가 3초 안에 읽힌다 (브랜치 `feature/r14-v34-r2`, 기준 `feature/r14-v34`)

공통 지침은 `docs/orchestration/worker-brief.md`를 따른다. 기준 브랜치만 `feature/r14-v34`로 바뀐다(r14-1·r14-3 통합본).

## 근거 문서
- 설계 기준: **DESIGN_V4 4.2절 1~5**, 4.5절.
- 앞 묶음 보고서: `docs/orchestration/reports/feature-r14-v34-r1.md`, `feature-r14-v34-r3.md`.

## 파일 소유
- 4절 머리의 r14-2 줄 그대로다: `CallCardOverlay.kt`, `CallCardView.kt`, `CallFollowupNotice.kt`, `StatusLights.kt`, `SelfCheckNotices.kt`, `RecordingGap.kt`(pendingText), `CallDigestWork.kt`(아침 보고 한 줄).
- 같은 시간에 r14-4가 `tools/device/call_card_test.sh`, `docs/REAL_DEVICE_CHECKLIST.md`, `screens/CallsScreen.kt`, `ScreensHomeCallsTest.kt`, 문서를 고친다. 건드리지 않는다.

## r14-1에서 넘어온 것
1. 오버레이에서 `CardStats.expanded(context)`를 부르고, 닫을 때 `CardStats.closed(context, shownMs)`를 부르게 연결한다.
2. `CallCardOverlay.storeText`의 모르는 번호 경로가 아직 큰 DB를 연다. 벨 경로에서는 카드 파일과 통화기록만 쓰게 바꾼다.
3. 카드 첫 줄 고르기(4.2-3)는 `ContactCard.Task.dueMs`·`checkReason`, `lastCallMs`, `calls30d`를 쓴다.
4. 잠금 상태에서는 창과 알림을 함께 띄운다(4.2-1). 통계는 r14-1의 CardStats가 locked로 센다.

## r14-3에서 넘어온 것
- 분석 신호등(4.2-5)은 설정 키 `routineEndedMs`에 `ResultChain.crons(s)`와 `ResultChain.runs(...)`를 써서 예정 슬롯을 계산한다.
