설계: `docs/DESIGN_V3.md` 5.3절 **r9-3** 전부. 사용자에게 보이는 v2.8의 큰 변화: 사람 이름을 누르면 **사람 화면**(소속·직책, 마지막 통화, 열린 체크할 일, 진행 중인 일, 최근 통화와 문자)이 열리고 그 자리에서 [전화 걸기] [문자 보내기].

## 담당 파일
- `screens/PersonScreen.kt`(신설, `AppScreen` 하위): 머리(이름 TITLE + 직책·업체 META + 원형 44dp [전화 걸기] [문자 보내기]) → "마지막 통화" 한 줄 → "체크할 일" `taskRow`(열린 것 전부, [다 됐어요]) → "진행 중인 일"(issue 제목·현황) → "최근 통화와 문자" `memoRow` 10건(배지 통화/문자/메일, 누르면 상세) → 글자 링크 [이름 고치기] [이 번호는 개인으로 두기](확인 시트 → `personal_numbers`, 이후 올리지 않음). 공유 번호면 "이 번호를 쓰는 사람: 박영희 대리 외 1명" + 사람 선택 칩. 번호는 화면에 쓰지 않음(다이얼러가 보여 줌). 테스트 태그 `person_*`.
- `MainActivity.kt`: `Screen.PERSON`(탭 없음, 뒤로 가면 왔던 화면으로)과 `a.openPerson(personId)`; 알림 extra는 건드리지 않음.
- 진입점(각 파일 최소 수정): `screens/CallsScreen.kt`(목록 행 이름, 상세 머리 이름), `screens/CompaniesScreen.kt`(사람 행을 누르면 사람 화면, 행의 ⋯ 메뉴 제거, 이름 고치기는 사람 화면으로), `screens/TasksScreen.kt`(META "김민수 님"), `screens/HomeScreen.kt`(오늘 통화 메모의 사람). 검색 결과(사람)는 있으면.
- 데이터: `IeumApplication.store(context)`의 기존 함수를 먼저 쓰고, 새 쿼리가 필요하면 `CallRecordStore` **클래스 끝에** `personCard(personId)` 같은 읽기 함수로 더하세요(r9-1·r9-2가 같은 파일을 고치고 있어 끝에 더해야 충돌이 작습니다). `ContactCards`(r9-2)는 아직 없으니 쓰지 마세요.
- 전화: `CallUi.dial(a,number)`; 문자: `ACTION_SENDTO` `smsto:`.
