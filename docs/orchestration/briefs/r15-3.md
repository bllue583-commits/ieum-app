# r15-3 지시문: 설정·알림·실행 파라미터 (v3.5, 기준 `feature/r15-v35` e9d6a06 — r15-0·r15-1·r15-2 통합됨)

공통 지침 `docs/orchestration/worker-brief.md`를 먼저 읽고 지킨다. 브랜치 `feature/r15-3-settings`. 설계: `docs/DESIGN_V5.md` 2.3절. r15-0·r15-1 보고서 요지(아래)를 반영한다.

## 이어받는 것
- r15-1이 만든 API: `suspend KakaoReport.link(activity):String?`(null 성공, "CANCELLED" 또는 코드), `suspend unlink(app)`, `linkState(app)`(UNAVAILABLE/NOT_LINKED/LINKED/BROKEN), `available()`, `sentToday(app)`, `suspend sendNow(app)`, 결과 상수 `ALREADY_SENT`·`NOT_LINKED`·`UNAVAILABLE`·`NO_REPORT`, 설정 키 `KAKAO_LAST_SENT_MS`·`KAKAO_FAILED_COUNT`·`MORNING_KAKAO`(없으면 켬). 시험 훅 `KakaoReport.senderFactory`·`appKey`·`clock`·`linker`.
- 매니페스트: MainActivity가 `kakao<키>://kakaolink?screen=calls&dayMs=<ms>` / `screen=tasks`를 받도록 intent-filter가 이미 선언됨.
- r15-0이 바꾼 것: `CallDigestText.evening(calls,newTasks,recordings,logged)`, `SelfCheckNotices.Input.updateWaiting`, `StatusLights.Input.textFailed·noMatchLong`, 주황 신호등이 있으면 신호등이 페이지 맨 위로 가고 방향 글이 "아래"로 바뀜.

## 할 일 (2.3절)
1. 설정 "아침 보고" 묶음(정리 묶음의 "알림 시각" 자리를 승격): `KakaoReport.available()`이 거짓이면 카톡 줄 전체를 숨기고 앱 알림 시각만. 참이면 [카카오톡으로 받기] 스위치(`MORNING_KAKAO`)와 상태 줄 — 연결됨이면 "연결됨, 매일 5:30에 보내요"와 마지막 전송("오늘 5:30에 보냈어요"/"어제 5:30에 보냈어요"), 연결 안 됨이면 [카카오톡 연결하기] 버튼(→ `link(activity)`), 연결이 풀렸으면 "카카오톡 연결이 풀렸어요" + [다시 연결]. [지금 보내 보기](하루 1회, `sendNow` 결과를 한국어 한 줄로), 연결 끊기(작은 글 버튼). 기존 `MORNING_HOUR` 앱 알림 시각은 그대로.
2. `CallDigestWork` 아침 알림: `MORNING_KAKAO` 켬 + `sentToday` 참이면 앱 알림을 띄우지 않는다. 실패·미연결·키 없음이면 지금처럼. 알림 첫 줄 순서는 보고서 순서(오늘·어제 요청과 확인 필요 먼저)로(평가 C-12).
3. `StatusLights` "알림" 줄: BROKEN이면 주황 "카카오톡 연결이 풀렸어요, 아침 보고 묶음에서 다시 연결", `KAKAO_FAILED_COUNT`가 연속 3일 이상 늘고 성공이 없으면 주황(마지막 성공 시각이 3일 넘게 지났고 연결 중이면). `SelfCheckNotices` 저녁 자가 진단: 연결 중인데 오늘 카톡이 안 갔으면 "아침 보고가 카카오톡으로 안 갔어요" 하루 1회.
4. `MainActivity`: intent data가 `kakao*://kakaolink`이면 `screen`·`dayMs` 쿼리를 읽어 기존 `MainActivity.intent(screen, dayMs)` 경로(통화 탭의 그 날짜 / 체크 탭)로 연다. 알 수 없는 값은 홈. `onNewIntent`도.
5. 시험(Robolectric): 키 없음 → 카톡 줄 숨김, 스위치 켬+전송 성공 → 아침 알림 없음, 실패 → 알림 있음, 실행 파라미터 → 화면, 신호등 세 상태, 자가 진단 줄. 화면 글 규칙(18sp, 가운데 점 금지, 영어 상태값 금지)은 ci가 검사.

## 파일 소유
`screens/SettingsScreen.kt`, `CallDigestWork.kt`, `StatusLights.kt`, `SelfCheckNotices.kt`, `MainActivity.kt`, 시험 파일. `pipeline/report/*`는 꼭 필요한 최소 수정만(보고서에 적기).
