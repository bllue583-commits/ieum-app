# r19-lab: 자막 실험실 — 음성을 직접 가져와 엔진을 시험한다 (사용자 지시 11/13)

브랜치 `feature/r19-asr-lab`(작업 나무 `/home/claude/wt/asrlab`, 기준 = `feature/r18-bench` dbaa579). 보고는 한국어.

## 왜
사용자 지시: "와이프가 받아쓰기를 왜 해, 너가 음성 파일을 직접 가져와서 자막을 테스트 해야지." 사람 받아쓰기를 기다리지 않고, **정답이 있는 공개 한국어 음성**을 이 작업 환경으로 가져와 앱과 같은 엔진·같은 설정으로 돌려 숫자를 낸다. 쓰임은 셋이다.
1. v3.9 엔진 결정(`docs/DESIGN_V7.md` 5.1~5.3)의 **정확도 절반**: (가) 지금 엔진 q5_0, (나) q8_0, (다) SenseVoice+VAD의 글자 오류율·숫자·이름·묵음 환각을 같은 음성으로 비교. 속도·전력은 폰 측정대의 몫이라 여기서는 참고만.
2. **은 정답지를 얼마나 믿을 수 있는가**: 나중에 아내 폰의 실제 통화 표본(업무 통화 WAV, 정답 없음)에 큰 모델로 기준 자막을 만든다. 그 방법(큰 모델 1개, 또는 2~3개 모델 합의)을 **정답이 있는 음성에 먼저 적용해** 기준 자막 자체의 오류율과, "모델끼리 숫자·이름이 다른 곳만 사람이 본다"고 했을 때 사람이 볼 양과 놓치는 오류의 비율을 잰다.
3. 실제 표본이 오면 바로 돌릴 수 있는 **도구**(폴더의 WAV → 엔진별 자막 → 기준 자막 → 숫자·이름 불일치 목록).
