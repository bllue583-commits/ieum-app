# r11-1 발신 번호와 통화 카드 서비스 (v3.0)

공통 지침 `docs/orchestration/worker-brief.md`를 먼저 읽고 따르세요. 브랜치 이름: `feature/r11-v30-r1`. 기준은 `feature/r11-v30`(v2.9 완성본).

설계: `docs/DESIGN_V3.md` 7절(7.1 동작, 7.2 기술 결정, 7.3 **r11-1**). v3.0의 큰 변화: 전화가 올 때·걸 때 통화 화면 위에 **이음 카드**(모모콜 방식).

## 담당 파일
- `pipeline/call/OutgoingCallService.kt`(신설): `CallRedirectionService`(매니페스트 `android.permission.BIND_CALL_REDIRECTION_SERVICE`, 역할 `ROLE_CALL_REDIRECTION`). `onPlaceCall`에서 번호를 `PhoneKey.of`로 `CallSession.pendingOutgoing(number, atMs)`에 적고 **즉시 `placeCallUnmodified()`**. 절대 redirect·cancel 안 함. 20초 안에 OFFHOOK이 오면 발신으로 확정(`CallSession` 수정, r10-1 구조 유지).
- `pipeline/call/CallCardService.kt`(신설): 포그라운드 서비스(type `phoneCall`, 권한 `FOREGROUND_SERVICE`+`FOREGROUND_SERVICE_PHONE_CALL`+`MANAGE_OWN_CALLS`; 시스템이 거부하면 `specialUse` 폴백). 수명: `CallSession`이 RINGING/OFFHOOK이 되면 `CallStateReceiver`가 `startForegroundService` → IDLE+3초 뒤 `stopSelf`. 10분 넘게 살아 있으면 스스로 종료(상태를 놓친 경우). 서비스가 `CallCardOverlay.show(context, phoneKey, state)` / `collapse()` / `hide()`를 부릅니다(**r11-2가 만드는 객체. 아직 없으면 같은 이름의 빈 object를 `pipeline/call/CallCardOverlay.kt`에 두되 보고서에 적고, 통합 때 r11-2 것으로 대체됩니다**).
- 권한·역할 흐름: 처음 설정 카드(`screens/HomeScreen.kt` setup 단계)에 "통화 화면 위에 이음 카드 보기"(`ACTION_MANAGE_OVERLAY_PERMISSION`)와 선택 단계 "거는 전화에도 카드 보기"(`RoleManager.createRequestRoleIntent(ROLE_CALL_REDIRECTION)`). 설정 "통화 카드" 묶음(`screens/SettingsScreen.kt`): 스위치 "전화 올 때 / 전화 걸 때 / 전화부에 없는 번호도", [카드 위치 처음으로]. 설정 키는 `PipelineSettingsKeys.CARD_INCOMING/CARD_OUTGOING/CARD_UNKNOWN/CARD_POS_Y`. 권한이 사라지면 처음 설정 카드에 다시 나타남.
- 매니페스트: 서비스 둘, 권한들, `SYSTEM_ALERT_WINDOW`.
- `docs/PRODUCT.md`(또는 설계 결정 표)에 "포그라운드 서비스 금지(v2.0)의 예외: 통화 중에만 도는 CallCardService"를 한 줄 — 문서는 오케스트레이터가 고치니 보고서에 문장만 적어 주세요.

## 다른 묶음
r11-2가 `CallCardOverlay`/`CallCardView`(오버레이 창, 헤드업 폴백 알림, USER_PRESENT 전환)를, r11-3이 시험·안전장치·하트비트 `callCard` 통계를 만듭니다. `CallSession`·`CallStateReceiver`(r10-1)는 필요한 최소만 고치세요.

## 시험
- Robolectric: `onPlaceCall` → `placeCallUnmodified` 호출과 `pendingOutgoing` 기록; 역할 없으면 발신 카드 없음; 서비스 수명(RINGING 시작 → IDLE+3초 종료, 10분 자가 종료); 권한 없으면 서비스가 오버레이 대신 알림 폴백 경로를 부름(`CallCardOverlay`가 빈 object면 호출 여부만 확인).
