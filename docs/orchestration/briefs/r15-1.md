# r15-1 지시문: 카카오 전송 (v3.5, 기준 `feature/r15-v35` a52801d)

공통 지침 `docs/orchestration/worker-brief.md`를 먼저 읽고 지킨다. 브랜치 `feature/r15-1-kakao`. 설계: `docs/DESIGN_V5.md` 0·0-1·1·2.1·5절 전부. 키 커밋이 `PipelineSettingsKeys`(KAKAO_*, REPORT_DAY, REPORT_SOURCE, MORNING_KAKAO), `PhoneStatus.V35`(kakao·report), `pipeline/report/KakaoReport.kt`(시그니처)를 넣었다 — **시그니처는 바꾸지 말고 몸통을 채운다**.

## 할 일
1. `build.gradle.kts`: Kakao Android SDK v2 2.26.0(`com.kakao.sdk:v2-user`, `v2-talk`, `v2-share`), `settings.gradle.kts`(android 폴더)에 `maven("https://devrepo.kakao.com/nexus/content/groups/public/")`. `BuildConfig.KAKAO_APP_KEY` = 환경 변수 `IEUM_KAKAO_APP_KEY`(영숫자만, 비면 빈 문자열) — `IEUM_INBOX_TOKEN` 처리와 같은 방식. `manifestPlaceholders["kakaoScheme"]`="kakao"+키(비면 "kakaonone"). 2.26.0이 이 환경에서 안 받아지면 받아지는 가장 가까운 2.2x 버전을 쓰고 보고.
2. `AndroidManifest.xml`: 카카오 로그인 `AuthCodeHandlerActivity`(scheme `${kakaoScheme}`, host `oauth`), 메시지 버튼 실행 파라미터용 intent-filter(scheme `${kakaoScheme}`, host `kakaolink`)는 **MainActivity에 선언만**(받아서 화면 여는 처리는 r15-3). `<queries>`에 카카오톡 패키지.
3. `KakaoReport.kt` 몸통: `available()`(키가 있을 때), SDK 초기화(앱 시작 경로에서 한 번 — `IeumApplication`에 한 줄 추가는 허용), 로그인(카카오톡 있으면 앱, 없으면 계정; 동의 항목 `talk_message`만), `linkState`, `compose`(1절·0-1절 결정: 피드 1통 + 오늘 챙길 일 텍스트 1통 ≤200자, 폴백 텍스트 4통, "외 n건", 모든 글 `maskNumbers` 재통과, 전화번호 0), `render()`(1080px 폭, 20sp 이상, 높이 ≤2400px, PNG ≤5MB; Robolectric에서 돌아야 함), `send`(업로드→피드→1초→텍스트, 실패 시 폴백 4통·실패한 통 1회 재시도, 같은 날 두 번 금지 `REPORT_DAY`, 카운터·오류 코드·`REPORT_SOURCE` 기록, 토큰 무효 → `KAKAO_LINKED=false`), `sentToday`, `sendNow`. 실제 SDK 호출은 `Sender` 구현(`KakaoSdkSender`) 하나에 몰고, 시험은 가짜 Sender.
4. `pipeline/report/ReportFetch.kt`(신설): 고유 작업 `ieum.report.morning` 매일 05:30 KST, 우편함 `report/<오늘>.json`을 ETag로(기존 결과 받기 코드의 GitHub contents 읽기 재사용), 없으면 05:35·05:45·06:00 재시도, 06:00에도 없으면 폰 폴백 1통(홈 첫 줄 규칙의 체크할 일 상위 4개, `report.source="phone"`), 네트워크 제약, 09:00 넘으면 보내지 않음. 앱 시작·부팅 때 예약 보장(기존 예약 함수 옆에 한 줄).
5. `PhoneStatus.kt`: 키 커밋의 V35 자리가 맞는지만 확인(필요하면 보정).
6. 시험(2.1-5): compose 고정 6사례, 각 통 ≤200자, 렌더 높이·전화번호 없음, 업로드 실패 → 텍스트 4통, 같은 날 재전송 금지, 404 → 재시도 체인 → 폴백, 토큰 실패 → linked=false, 하트비트 kakao/report 키.
